Applications and agents that hand bounded decisions to Jev or an open counterpart. Most report demonstrations or the builders’ own measurements.

Judging & evaluation

  • openlayer-ai/jevals ↗

    Agent evals and guardrails expressed as typed decisions: all checks for a trace go out as one request to Jev, local Kev or Laya, or another decision model.

Agents & tool use

  • awlevin/typesafe-computer-use ↗

    macOS computer-use agent that reads the screen with OCR, asks Jev for the next action and calls a writing model only when free text is needed.

  • Bodila51/grok-bot-jev ↗

    Reference router in which Jev decides whether a chatbot agent may reuse an artefact, stop a failing retry, cap research or ask for approval.

  • browser-use/jev-ultrafast ↗

    Browser agent in which Jev picks an operation and an indexed page element; a small LLM writes text only for TYPE_TEXT.

  • droidrun/mobile-jev ↗

    Android phone agent driven by Jev through the Mobilerun API, with execution traces and request-level timings.

  • ipenywis/laya-ultrafast ↗

    Local port of the jev-ultrafast browser agent that makes each decision with the open Laya model through MLX instead of the hosted API.

  • milind-soni/tiptour-macos ↗

    macOS menu-bar assistant whose text mode lets Jev choose among locally detected screen controls, which the app executes and validates step by step.

  • wy-coliney/jev-browser-use ↗

    Browser skill for Codex in which Jev handles navigation, clicks, toggles and scrolling while Codex keeps text input, visual judgment and the final check.

Agent memory

  • libingzheren/Jev-Mem ↗

    Agent memory system with a Jev System-One control plane, a multi-relational memory plane and a System-Two reasoning plane.

  • tamaratran/fast-jev-compaction ↗

    Claude Code plugin that replaces compaction summaries with Jev keep-or-drop decisions on every tool call and result, keeping what remains verbatim.

  • zilliztech/memsearch ↗

    Cross-platform semantic memory layer for coding agents with optional Jev reranking of memory search results.

Coding & software

  • devagrawal09/jev-review ↗

    Staged code-review workflow that keeps orchestration in code and asks Jev bounded judgments about diff hunks and source regions.

  • samuelfaj/distill ↗

  • sedum-dev/sedum ↗
