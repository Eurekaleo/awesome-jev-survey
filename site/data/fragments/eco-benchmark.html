Leaderboards, benchmark kits and independent evaluations of Jev and Jev-like models.

Benchmark

AbdelStark/jev-benchmarks ↗

Probability-aware evaluation harness (calibration, selective risk, resources, latency); first study compares Jev with GLiNER2.5 on BTZSC.

Boundary Pilot of 300 held-out examples; statistics need recomputation before citation.

Benchmark · Embodied control & games

AlperKartkaya/FlightBench ↗

Fixed-wing landing simulator and benchmark in which Jev, LLMs, classical controllers and people command the actuators from the same state.

Boundary Author-run flights; the README presents Jev’s landing as successful but not a top score.

Benchmark

apolinario/decision-index ↗

Reproduction kit for the Decision Index, a typed-decision benchmark of 38 tasks in five areas that can be rebuilt from public sources and run locally or as one Hugging Face job.

Boundary Area weights and scorers change between versions; models slower than 1 s per request on the maintainers’ GPU are not admitted.

Locked benchmark of whether Jev reranking improves a small Turkish RAG system (1,044 XQuAD-TR questions) in quality, latency and cost.

Boundary One language and one corpus; all model calls through OpenRouter.

Data behind jevals.com: boards and per-decision logs that score Jev and LLMs on yes/no, choice and score questions against human labels for Decision Score, accuracy, calibration, cost and speed.

Boundary Three public tasks per release; every board number can be recomputed from the logs (CC BY 4.0).

Evaluation · Search, retrieval & ranking

anessbelbati/jev-rerank-bench ↗

Reranking benchmark over 14 datasets comparing Jev prompt designs with Cohere Rerank 4, zerank-2 and a chat-model baseline, with every raw API response saved.

ReportsReranking: ties Cohere Rerank 4 Pro at half the latency

Boundary Single author; the ranking between Jev and Cohere depends on how datasets and questions are weighted.

Evaluation · Security & fraud

bitnovus/jev-spam-eval ↗

Zero-shot spam and phishing classification with Jev yes/no questions and written category definitions, compared with TF-IDF logistic regression on the same evidence.

ReportsZero-shot spam: matches a trained baseline; catches more new phishing

Boundary A TF-IDF model trained on about 4,600 labelled messages per fold matched Jev on the main test.
